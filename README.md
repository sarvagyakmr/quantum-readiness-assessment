# Quantum Readiness Assessment

An interview tool that assesses an organisation's readiness for the move to post-quantum cryptography.

- **Part A, Leadership readiness:** 10 objectives rated L0 to L3, structured on the Cyber Security Agency of Singapore's Quantum Readiness Index (V1, July 2026).
- **Part B, Technical exposure:** questions on data lifespan, TLS, certificates, keys, applications, network access, vendors and crypto-agility. Questions adapt to the selected industry and technology footprint.

The tool is a single static HTML file with no server. Answers are stored only in the browser of the person filling it in and can be saved to a file.

This is an independent assessment tool, not an official CSA or MAS product.
